# S3

Module: `aws/s3`

Creates one private bucket and a paired `${name}-logs` bucket for
server access logs. Callers pass `name` and optional `tags`. There are
no inputs for encryption, versioning, public access, logging, or
destroy-on-delete.

Bootstrap uses this for Terraform state and the shared Lambda artifact
bucket.

## Locked defaults

- Versioning enabled
- AES-256 encryption
- All public access blocked
- Object ownership `BucketOwnerEnforced`
- Bucket policy denies non-TLS (`aws:SecureTransport = false`)
- Server access logs go to `${name}-logs` (that bucket does not log to itself)
- `force_destroy = false`

## Caller

```hcl
module "lambda_artifacts" {
  source = "git::https://github.com/developer-experience-DevEX-platform/terraform-modules.git//aws/s3?ref=v0.3.0"

  name = "devex-lambda-artifacts-123456789012"
  tags = {
    Purpose = "LambdaArtifacts"
  }
}
```

`name` must be a valid S3 bucket name at most 58 characters so
`${name}-logs` stays within the S3 limit.

## Inputs

| Input | Required | Notes |
| --- | --- | --- |
| `name` | yes | Globally unique bucket name. |
| `tags` | no | Merged with `ManagedBy=Terraform` and `Platform=DevEx`. |

## Outputs

| Output | Notes |
| --- | --- |
| `id` | Bucket ID. |
| `arn` | Bucket ARN. |
| `name` | Bucket name. |
| `bucket_regional_domain_name` | Regional domain name. Used by [CloudFront](cloudfront.md). |
